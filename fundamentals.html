CIA Triad & Basic Concepts

The CIA Triad—Confidentiality, Integrity, Availability—is the bedrock of cybersecurity, ensuring data security, accuracy, and access. Let’s explore these pillars deeply!

Confidentiality

Restricts data access to authorized users only, using encryption and access controls.

  • Prevents unauthorized disclosure (e.g., Equifax 2017 breach).
  • Techniques: AES-256, RBAC.
openssl enc -aes-256-cbc -in data.txt -out data.enc
💡 Tip: Always use strong passwords with encryption keys!

Integrity

Ensures data remains unaltered with hashing and signatures.

  • Detects tampering (e.g., SolarWinds 2020 attack).
  • Tools: SHA-256, GPG.
sha256sum file.txt
⚠️ Warning: Regularly verify hashes to catch modifications!

Availability

Guarantees system access with redundancy and protection.

  • Defends against DoS (e.g., Dyn 2016 attack).
  • Solutions: Load balancers, rate limiting.
nginx -c /etc/nginx/nginx.conf
🌐 Fun Fact: Redundancy saved many sites during the Dyn outage!

Additional Concepts

Key principles include:

  • Authentication: Verifies identity (e.g., 2FA).
  • Authorization: Sets permissions (e.g., Active Directory).
  • Non-repudiation: Ensures traceability (e.g., digital signatures).

Threat Modeling

Threat modeling proactively identifies and mitigates risks. Dive into this critical process!

STRIDE Model

Categories threats into six types.

ThreatDescriptionMitigation
SpoofingImpersonationStrong auth
TamperingData alterationHashing
RepudiationAction denialLogging
Info DisclosureData leakEncryption
DoSAccess disruptionRedundancy
ElevationPrivilege gainLeast privilege
💡 Pro Tip: Use STRIDE to prioritize high-impact threats!

Process

  • Define system (e.g., web app architecture).
  • Identify assets (e.g., user data).
  • List threats (e.g., SQL injection).
  • Prioritize risks (e.g., impact score).
  • Mitigate with controls (e.g., input validation).

Example: Web App

Threat: SQL injection. Mitigation with prepared statements.

const stmt = db.prepare('SELECT * FROM users WHERE username = ? AND password = ?');
stmt.run(username, password);
⚠️ Caution: Always sanitize inputs to prevent injection!

Tools

  • Microsoft Threat Modeling Tool.
  • OWASP Threat Dragon (open-source).

Real-World Case

Twitter 2020 hack: Weak auth exploited via social engineering.

🌐 Fun Fact: Threat modeling could’ve prevented this breach!

Risk Assessment

Steps

  • Identify assets (e.g., databases).
  • Assess threats (e.g., ransomware).
  • Evaluate likelihood and impact.
  • Calculate score (Likelihood × Impact).
  • Plan mitigation (e.g., backups).

Cryptography Basics

Cryptography secures data with encryption and more. Explore this fascinating field!

Symmetric Encryption

Uses one key for speed and efficiency.

openssl enc -aes-256-cbc -in data.txt -out data.enc
openssl enc -aes-256-cbc -d -in data.enc -out data.txt
💡 Tip: Rotate keys every 6 months for security!

Asymmetric Encryption

Uses key pairs for secure communication.

openssl genrsa -out private.pem 2048
openssl rsa -in private.pem -outform PEM -pubout -out public.pem

Hashing

Creates unique data fingerprints.

echo -n "data" | sha256sum
🌐 Fun Fact: SHA-256 is used in Bitcoin mining!

Digital Signatures

Ensures authenticity and integrity.

gpg --sign document.txt
gpg --verify document.txt.gpg

Key Management

  • Use AWS KMS or HashiCorp Vault.
  • Rotate keys regularly.

Real-World Case

Heartbleed 2014 exposed keys due to a buffer overflow.

⚠️ Warning: Patch systems to avoid Heartbleed-like issues!
